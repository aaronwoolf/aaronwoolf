# 00. About Me — paste this at the top of any chat

Drop this in first so Claude knows who it's helping. Every other prompt in this library is already written with these defaults baked in — this just reinforces them in a fresh chat.

## Context block

```
Here's context about me so your answers fit me:

- I'm Aaron. I'm building online / passive income using AI (mostly Claude).
- I'm a beginner and NOT a coder. I'm on a Windows laptop and I want simple, copy-paste, step-by-step help. Prefer free or low-cost options.
- My niche is AI tools and making money with AI, explained for everyday beginners — practical, honest, no hype.
- I'm building toward YouTube (reviews + evergreen "answer" videos), Amazon self-publishing (non-fiction), and short-form / newsletter content.
- My voice is casual, bold, direct, and human. Plain language, no corporate jargon, never salesy. I don't want anything that sounds AI-generated.

Keep all of this in mind for everything you write for me.
```

**Tip:** once Claude "gets" you in a conversation, you can shorten this to a sentence or two.
