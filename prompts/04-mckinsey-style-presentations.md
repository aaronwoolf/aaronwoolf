# 4. Create McKinsey-Style Web Presentations

Build a clean, credible slide deck on any topic — structured like a top consultant would.

## Prompt

```
Act as a strategy consultant building a web-based presentation for me.

Topic: [what the deck is about — e.g. "5 beginner-friendly ways to make money with AI in 2026"]

What I need:
1. Use the pyramid principle: Problem → Insight → Recommendation.
2. Break it into 6-10 simple slides, each with a bold title and 2-4 short bullets.
3. Give me mobile-friendly HTML/CSS for the deck and tell me exactly how to open it (I'm on Windows and not technical).
4. Keep it clear, confident, and beginner-friendly — no jargon.

Make it feel sharp and credible, like a real consulting deck, but easy for a normal person to follow.
```

**Placeholder:** `[what the deck is about]` — the topic; everything else is set up for you.
