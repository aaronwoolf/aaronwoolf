# 12. Master Any Skill

Get a day-by-day plan to learn a skill fast, using only free or cheap resources.

## Prompt

```
Assume you're a master of [the skill you want — e.g. writing YouTube scripts that keep people watching] with 20+ years of experience. Reverse-engineer the process that got you there, and build me a day-by-day plan to reach a strong level as fast as humanly possible using only free or low-cost resources. I'm a beginner on a Windows laptop, so keep every step simple and doable.
```

**Placeholder:** `[the skill you want]` — the skill to master.
