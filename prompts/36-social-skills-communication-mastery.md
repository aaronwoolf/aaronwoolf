# 36. Social Skills & Communication Mastery

Level up one people-skill with techniques, drills, and a 30-day confidence challenge.

## Prompt

```
I want to improve my [which — public speaking / networking / difficult conversations / active listening] skills. My current challenge is: [describe it]. Give me: 5 specific techniques to improve, each with an example; practice exercises I can do alone and with others; common body-language mistakes to avoid; conversation frameworks for different situations (small talk, professional networking, deeper connections); and a 30-day challenge to build my confidence.
```

**Placeholders:** `[which skill]`, `[describe your challenge]`.
